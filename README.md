# Portofolio Munib Tahta

Situs portofolio pribadi berbasis HTML, Bootstrap, Sass, dan JavaScript.

## Menjalankan situs

Buka `index.html` di browser. Aset CSS, JavaScript, font, dan gambar yang dipakai situs tersedia di repositori.

## Build aset

Proyek ini memakai Gulp. Pasang dependensi dengan `npm install`, lalu jalankan `./node_modules/.bin/gulp` untuk menjalankan task build yang tersedia.

- Sumber Sass: `scss/`
- CSS: `css/`
- JavaScript: `js/`
- Aset gambar: `img/`
- Pustaka pihak ketiga: `vendor/`

Berkas CSS/JavaScript hasil minifikasi dan folder `vendor/` disimpan di repositori karena dirujuk langsung oleh `index.html`.
